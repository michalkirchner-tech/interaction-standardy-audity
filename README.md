# Standardy a audity – INTERACTION

Webová aplikace pro standardy a audity karosáren a lakoven podle značek
(Arval, Stellantis, Mercedes-Benz, Škoda Auto, Porsche ČR, Volvo, Mitsubishi, Hyundai).

Čistě statický web (HTML + CSS + JS), běží na GitHub Pages bez serveru.

## Spuštění lokálně
Otevřete `index.html` v prohlížeči.

## Zdroje log
Loga značek jsou ochranné známky jejich vlastníků. Staženo z oficiálních webů
(arval.cz, porsche.co.cz) a z Wikimedia Commons.
